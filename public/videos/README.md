# Hero video

Add the approved silent MP4 as `costa-rica-hero.mp4` in this directory and redeploy.
The hero detects the file at build time. Until then it uses the new editorial
photograph and makes no request to a missing video.

Recommended web export: H.264, 1920×1080, 24 fps, 8–10 seconds, no audio track,
fast-start enabled, ideally under 5 MB. A static image remains visible if playback
fails, and video is disabled for reduced motion and data-saving preferences.

See `docs/gemini-hero-prompt.txt` for the generation prompt.
